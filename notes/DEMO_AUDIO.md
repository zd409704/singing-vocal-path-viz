# Demo audio: source and license

File: `assets/demo_audio/amazing_grace_synth.wav` (43.4 s, 44.1 kHz, 16-bit mono)

**Source.** Newly synthesized by `pipeline/synth_demo_voice.py`, a from-scratch formant synthesizer in this program. No recording of any person, and no sample library, went into it. Re-running the script with its default seed regenerates the clip.

**Not from the reference video.** The soundtrack of `notes/reference/source-post-2119421849134305644.mp4` was never decoded, extracted or used. The only tool run on that file was `ffprobe`, to read its stream properties.

**Voice.** Synthetic, with formant targets in the range of published adult female vowel averages. It is not a model or imitation of any real singer.

**Song.** First verse of "Amazing Grace": text by John Newton (published 1779), tune "New Britain" (first published 1829). Both are public domain. The note-for-note arrangement in the script was written for this program from memory of the tune, and may differ from any published setting.

**Use.** The clip is generated by this program, so the program may use it. No separate license has been assigned; that is for the owner to decide if it is ever distributed.
